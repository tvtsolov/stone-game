# Go
This is my attempt to code Go for GameMaker. The language is called GML. The project allows for two people on the same PC to play a game of go up to the end on a board size 9X9, 13X3 and 19X19 (in progress).

## Starting the game
Currently to run the project you need to download the project and install Game Maker.

I will add other ways to run it with less hassle, I am currently working on some of the functionalities that need fixing before I do that.
